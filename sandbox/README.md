# Sandbox

Throwaway trials for decision records. Everything here except this file is ignored by
git and skipped by QC.

Rules:

1. One folder per decision and option: `sandbox/DR-001/<option>/`.
2. Every option gets the same sample content, so the comparison is fair.
3. Each trial is time-boxed before it starts (the box is written in the decision record).
4. Results go into the decision record's Evidence section. Nothing in the sandbox is
   used by the real site or examples; the chosen option is rebuilt cleanly in its step.
