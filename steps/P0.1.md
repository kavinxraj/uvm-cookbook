# P0.1: Repository, workflow, QC harness

Roadmap entry: see `ROADMAP.md`, step P0.1. Loop: see `WORKFLOW.md`.

## Plan

- **Goal:** A git repository with the agreed process (PLAN -> DISCUSS -> REFINE ->
  IMPLEMENT -> FEEDBACK -> PASS/FAIL -> COMMIT) enforced by tools, and a QC harness that
  produces tool feedback for every later step.
- **Scope (in):** process documents, step tracker, QC runner, git hooks, setup script.
- **Scope (out):** site skeleton (P0.2), simulation flow (P0.3), regression/mutants (P0.4),
  CI and license (P0.6).
- **Deliverables:** `README.md`, `CLAUDE.md`, `PLAN.md`, `ROADMAP.md`, `WORKFLOW.md`,
  `steps/_template.md`, `tools/step.py`, `tools/qc.py`, `tools/setup.sh`,
  `tools/requirements.txt`, `.githooks/pre-commit`, `.githooks/commit-msg`, `.gitignore`,
  `.codespellrc`.
- **Gates (tool):** `qc.py` overall PASS; hooks refuse a commit with no `Step:` trailer
  and a commit whose step is not `pass`.
- **Gates (human):** the workflow and roadmap match what was asked.
